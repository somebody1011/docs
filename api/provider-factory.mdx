`ProviderFactory` is used internally by `FintechSDK` to create and validate provider instances. You typically don't need to call it directly — use `FintechSDK` instead. However, it's available if you need direct provider access.

## `ProviderFactory.createProvider()`

```typescript
static createProvider(provider: ProviderType | string, config: any): baseProvider
```

Validates the supplied config and returns an instantiated provider. The provider string is matched case-insensitively against the `ProviderType` enum values.

<ParamField body="provider" type="ProviderType | string" required>
  Provider identifier. Accepts `ProviderType` enum values (`ProviderType.pesapal`, `ProviderType.clickpesa`) or equivalent strings (`"pesapal"`, `"clickpesa"`). Matching is case-insensitive.
</ParamField>

<ParamField body="config" type="any" required>
  Configuration object for the provider. Required fields vary by provider — see the table below.
</ParamField>

**Returns:** A `PesapalProvider` or `ClickpesaProvider` instance, typed as `baseProvider`.

**Throws:**

- `"Invalid configuration: Missing required fields for Clickpesa."` — one or more required ClickPesa fields are missing.
- `"Invalid configuration: Missing required fields for Pesapal."` — one or more required PesaPal fields are missing.
- `"Unsupported provider type: {provider}"` — the provider string does not match any known provider.

### Required config fields

| Field | PesaPal | ClickPesa |
| --- | --- | --- |
| `baseUrl` | Required | Required |
| `PESAPAL_CONSUMER_KEY` | Required | — |
| `PESAPAL_CONSUMER_SECRET` | Required | — |
| `CLICKPESA_CLIENT_ID` | — | Required |
| `CLICKPESA_API_KEY` | — | Required |

### Example (direct use)

```typescript
import { ProviderFactory } from 'finconnect';

const provider = ProviderFactory.createProvider('pesapal', {
  baseUrl: process.env.PESAPAL_BASE_URL!,
  PESAPAL_CONSUMER_KEY: process.env.PESAPAL_CONSUMER_KEY!,
  PESAPAL_CONSUMER_SECRET: process.env.PESAPAL_CONSUMER_SECRET!,
});

// Call provider methods directly
const token = await provider.authenticate();
```

<Note>
  For most use cases, use `FintechSDK` instead of calling `ProviderFactory` directly. `FintechSDK` handles provider instantiation and normalises the `pay()` call for each provider.
</Note>
